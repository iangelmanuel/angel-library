> Obra original de **Allen B. Downey**, traducción al español de **Miguel Ángel Durán ([midudev](https://midu.dev))**. Licencia Creative Commons BY-NC-SA 4.0.

**Think Python** es una introducción a Python para quien nunca ha programado, o para quien lo intentó y se atascó. Esta edición traduce la **tercera edición** de _Think Python: How to Think Like a Computer Scientist_.

No enseña Python como catálogo de sintaxis: enseña a pensar como programador y usa Python para ello. De ahí que empiece por "programar como una forma de pensar" y no por "instala esto".

## Cómo se lee

Los 19 capítulos están publicados como **notebooks que se abren en Google Colab**, así que se ejecutan en el navegador sin instalar nada. También se puede **descargar el libro completo en PDF**.

## Los capítulos

1. Programar como una forma de pensar
2. Variables y sentencias
3. Funciones
4. Funciones e interfaces
5. Condicionales y recursión
6. Valores de retorno
7. Iteración y búsqueda
8. Cadenas y expresiones regulares
9. Listas
10. Diccionarios
11. Tuplas
12. Análisis y generación de texto
13. Archivos y bases de datos
14. Clases y funciones
15. Clases y métodos
16. Clases y objetos
17. Herencia
18. Extras de Python
19. Reflexiones finales

## Para practicar y para enseñar

Cada capítulo tiene además un **notebook en blanco**: el mismo texto con la mayor parte del código eliminado. Sirve para rellenar los huecos y comprobar si de verdad seguiste el razonamiento o solo leíste código que ya funcionaba. El autor los ofrece como material para docentes, pero funcionan igual de bien estudiando en solitario.

## Dónde encaja

Es material de fundamentos, no de proyectos: sales sabiendo pensar en estructuras de datos, recursión y clases, no habiendo montado una API. Como primer libro de programación —o como repaso ordenado si aprendiste a saltos— es difícil de mejorar, y que esté en español con notebooks ejecutables quita las dos excusas habituales para no terminarlo.

Las versiones impresa y electrónica del original en inglés están en Bookshop.org y Amazon, y la página del libro vive en Green Tea Press.
