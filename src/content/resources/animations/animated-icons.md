## Cuándo aporta valor

Un icono animado puede confirmar una acción, señalar un cambio de estado o dirigir la atención a un control importante. Si el movimiento no comunica nada, un icono estático suele ser más claro y ligero.

## Antes de incorporarlo

- Elige el formato que ya soporte el proyecto; Lottie necesita un reproductor, mientras que SVG puede integrarse directamente en la web.
- Conserva una alternativa comprensible si la animación no se reproduce.
- Reduce o elimina el movimiento cuando el sistema del usuario active `prefers-reduced-motion`, una preferencia de accesibilidad para limitar animaciones.
