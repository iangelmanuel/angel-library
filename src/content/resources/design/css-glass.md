## Qué puedes ajustar

El generador permite cambiar transparencia, desenfoque, saturación, borde y sombra mientras muestra el resultado. El CSS obtenido es un punto de partida para una tarjeta o panel colocado sobre un fondo con detalle.

## Cuándo evitarlo

- Si el texto pierde contraste al cambiar el contenido que queda detrás.
- Si el desenfoque es la única señal que separa el panel del fondo.
- Si muchas superficies aplican el efecto al mismo tiempo y dificultan la jerarquía.

Adapta los valores a las variables del proyecto y comprueba el rendimiento en dispositivos modestos antes de convertir el efecto en un estilo global.
