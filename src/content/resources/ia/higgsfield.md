**Higgsfield** es una plataforma web para generar y editar imágenes y videos con inteligencia artificial. Combina modelos propios con modelos de distintos proveedores en un mismo espacio de trabajo, de modo que se puede comparar el resultado sin configurar cada servicio por separado.

## Funcionalidad principal

| Flujo                    | Qué permite                                                               |
| ------------------------ | ------------------------------------------------------------------------- |
| Texto a imagen           | Crear conceptos, escenas, producto, retratos y material de campaña        |
| Edición de imagen        | Sustituir objetos, fondos, colores o texto dentro de una zona              |
| Texto o imagen a video   | Generar movimiento desde una descripción o un fotograma inicial           |
| Referencias              | Guiar identidad, estilo, composición y consistencia entre piezas          |
| Control de movimiento    | Usar movimientos de cámara predefinidos o transferir movimiento           |
| Cinema Studio            | Elegir óptica, distancia focal, encuadre, iluminación y movimientos       |

La plataforma integra varios modelos de imagen y video. Cada uno responde de manera diferente y puede tener límites propios de duración, resolución, referencias y coste; el nombre del modelo forma parte de la decisión creativa, no es una opción intercambiable sin consecuencias.

## Flujo recomendado

1. Define el formato final, la relación de aspecto y el plano que necesitas.
2. Genera o carga una imagen base y corrige composición, texto y detalles antes de animarla.
3. Usa una referencia de movimiento, fotogramas inicial y final o controles de cámara cuando necesites mayor previsibilidad.
4. Produce primero una prueba corta y de menor coste.
5. Revisa continuidad, manos, rostros, logotipos, física y cambios entre fotogramas antes de exportar.

## Cuándo encaja

- Previsualización de anuncios, videoclips y escenas antes de una producción real.
- Animar una fotografía, un producto o una ilustración existente.
- Mantener un personaje o una dirección visual a través de varias piezas.
- Probar diferentes modelos sin mover manualmente los archivos entre servicios.

## Planes y precauciones

Se puede empezar con acceso gratuito limitado; los modelos, la resolución alta, el volumen de generaciones y las funciones de equipo dependen de créditos o planes de pago. Como la oferta cambia con frecuencia, comprueba el coste del modelo seleccionado antes de lanzar lotes.

Las referencias se cargan en un servicio externo. No subas material confidencial ni imágenes de personas sin permiso, y revisa las condiciones comerciales de la plataforma y del modelo usado antes de publicar el resultado.
