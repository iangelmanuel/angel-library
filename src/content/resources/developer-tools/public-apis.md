## Para qué sirve

El catálogo ayuda a encontrar una API con datos reales para practicar solicitudes HTTP, construir un prototipo o comparar proveedores. Una entrada en la lista es un punto de descubrimiento, no una garantía de calidad ni de permanencia.

## Antes de depender de una API

Revisa su documentación, autenticación, límites de solicitudes, licencia de los datos y política de disponibilidad. Prueba también errores y tiempos de espera. Si el proyecto va a producción, evita llamar desde el navegador con una clave secreta y diseña qué ocurrirá cuando el servicio externo falle o cambie.
