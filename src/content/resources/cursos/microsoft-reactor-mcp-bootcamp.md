> Publicado por **Microsoft Reactor**, el programa comunitario de formación de Microsoft.

Bootcamp de **Microsoft Reactor** sobre el **Model Context Protocol**, el estándar que permite a un modelo descubrir y usar herramientas externas.

| | |
| --- | --- |
| Idioma | Español (LATAM) |
| Sesiones | 4 directos |
| Fechas | 18 de agosto a 1 de septiembre de 2025 |
| Formato | En vivo, disponible bajo demanda después |
| Precio | Gratis |

Como las fechas ya pasaron, hoy se consume como material grabado.

## Qué cubre

- Crear un servidor MCP desde cero.
- Integrarlo con un modelo desde **VS Code** y **GitHub Copilot**.
- Comunicación en tiempo real con **Server-Sent Events**.
- Despliegue en **Azure Container Apps**.

## No confundir las dos series

Los dos bootcamps de Reactor circulan con descripciones cruzadas. Para ubicarlos:

| Serie | Contenido real |
| --- | --- |
| `S-1567` | MCP Bootcamp LATAM, esta |
| `S-1633` | [Python + Agentes con Agent Framework](/resources/cursos/microsoft-reactor-python-agentes) |

El parámetro `?wt.mc_id=` que a veces acompaña al enlace es solo seguimiento de campaña y se puede quitar.

## Otra ruta para lo mismo

Si prefieres un taller escrito y autoguiado en vez de directos, [Learn MCP de Cloudflare](/resources/cursos/cloudflare-learn-mcp) cubre el mismo protocolo con otro proveedor de despliegue.
