Certificación de **freeCodeCamp** que enseña inglés de nivel **A2** usando situaciones propias del trabajo en desarrollo de software: reuniones, correos, revisiones de código, presentaciones.

| | |
| --- | --- |
| Nivel | A2 del marco europeo, elemental |
| Dedicación estimada | Unas 300 horas |
| Precio | Gratis |
| Certificado | Sí, verificado y gratuito |
| Estado | Beta |

Hay **versión en español** de la interfaz, que es la enlazada aquí: las instrucciones se leen en español y se practica el inglés.

## Por qué está en una biblioteca de programación

El inglés es la barrera silenciosa de muchas carreras técnicas. La documentación, los mensajes de error, las discusiones en GitHub y buena parte de las entrevistas están en inglés, y ningún framework compensa no poder leerlos.

Lo que distingue a este curso de uno genérico es el **contexto**: el vocabulario y los diálogos son de un equipo de desarrollo, no de reservar un hotel.

## Qué esperar

- **A2 es un nivel elemental.** Cubre presentarse, describir tareas rutinarias y entender frases sencillas. No basta para una entrevista técnica en inglés, pero es la base para llegar ahí.
- **Está en beta**, así que puede haber cambios en el temario o en el examen.
- Las 300 horas son una estimación; con base previa se recorre bastante más rápido.
