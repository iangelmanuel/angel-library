## Qué cubre hoy

- **Get Started with Testing**, 7 lecciones: fundamentos, pruebas automatizadas frente a manuales, dónde ejecutarlas y buenas prácticas.
- **Assertions and Other Primitives**, 1 lección.

Dentro de esas secciones aparecen pruebas unitarias y de componentes con ejemplos de React y Lit, análisis estático con TypeScript y ESLint, y pruebas de backend con Node.js.

## Lo que todavía no está

Varias secciones siguen marcadas como próximas: testing guiado por el problema, testing automatizado en la práctica, filosofía del testing y cómo escribir código que se pueda probar.

Conviene saberlo antes de planificarlo como formación completa: **hoy es una introducción sólida, no un curso cerrado**.

## Por qué merece la pena igual

La parte publicada dedica tiempo a algo que casi ningún tutorial hace: **por qué** se prueba y **qué** conviene probar, antes de enseñar la sintaxis de una herramienta. Esa parte no caduca aunque cambies de framework de pruebas.
