> Repositorio de **Miguel Ángel Durán**, [Midudev](https://github.com/midudev).

Repositorio que acompaña al curso de React de Midudev: apuntes en Markdown, ejemplos y los proyectos que se construyen durante las clases.

Ronda las 9.000 estrellas y su última actualización es de 2026.

## Cómo usarlo

La forma que mejor funciona es tenerlo abierto **junto al video**, no antes ni después:

1. Sigue la clase escribiendo tú el código.
2. Cuando algo no funcione, compara con el archivo correspondiente del repositorio.
3. Al terminar el módulo, lee el apunte en Markdown para fijar los conceptos.

Leer el repositorio sin ver el curso deja fuera el porqué de cada decisión, que es la parte que no está en el código.

## Nota sobre las versiones

React cambia, y un repositorio de curso refleja el estado del ecosistema cuando se grabó. Antes de copiar una configuración —sobre todo de herramientas de build o de enrutado— vale la pena comprobar la fecha del último cambio y contrastar con la documentación oficial de React.
