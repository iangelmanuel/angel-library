> Apuntes hechos y compartidos gratis por **Majo Ledesma** ([majoledesma](https://github.com/majoledesma) en GitHub).

Colección de **apuntes hechos a mano** sobre lenguajes y temas de programación, publicados en español y gratis por Majo.

## Qué hay

| Tema | Nivel |
| --- | --- |
| JavaScript | Básico |
| React | Avanzado |
| Python | Básico |
| Programación orientada a objetos con Python | Intermedio |
| Git | Básico |
| SQL | Básico |
| Buenas prácticas de CSS | Básico e intermedio |
| Swift | En sitio aparte, alojado en Notion |

La mayoría son **PDF servidos desde Google Drive**.

## Para qué sirven y para qué no

**Sirven** como repaso rápido y como material de consulta visual: al estar escritos a mano, con esquemas y flechas, se recorren mucho más rápido que un texto corrido. Van bien impresos o en el móvil justo antes de una entrevista.

**No sustituyen** a un curso: son apuntes, no explicaciones extensas. Asumen que ya viste el tema alguna vez y quieres recuperarlo.

## Dos avisos prácticos

- **Dependen de Google Drive.** Si un enlace deja de funcionar, no hay copia alternativa en el propio sitio. Conviene descargar lo que te interese en vez de confiar en el enlace.
- **Sin fecha visible.** No se indica cuándo se escribió cada apunte. Para Git o SQL da igual; para React sí importa, porque el ecosistema cambia rápido.
