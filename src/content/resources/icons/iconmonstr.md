## Cuándo encaja

Permite buscar y descargar un icono concreto sin añadir una dependencia al proyecto. Es una opción práctica para una página pequeña, una ilustración puntual o un formato que deba editarse antes de integrarlo.

## Antes de publicarlo

Comprueba el acuerdo de licencia mostrado para el icono y conserva consistencia con el resto de la interfaz: mismo grosor, tamaño visual y tratamiento de relleno. Si el proyecto necesita decenas de símbolos o componentes para varios frameworks, una biblioteca versionada suele ser más fácil de mantener.
