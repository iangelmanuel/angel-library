No es un paquete: es una colección de bloques HTML+Tailwind (hero sections, pricing, tablas, formularios) que se copian tal cual desde la web. Sin dependencia npm, sin plugin, sin JS — lo único que hace falta es tener Tailwind CSS ya configurado en el proyecto.

## Cuándo la uso

Para arrancar rápido una sección de marketing o un layout estándar (login, pricing, 404) sin escribir el markup desde cero, y después ajustar clases a mano.

## Tips

- Al ser copy-paste puro, no hay que preocuparse por versiones ni breaking changes — el código copiado es 100% del proyecto desde el día uno.
- Los componentes con interactividad (dropdowns, accordions) traen el HTML pero no el JS: hay que agregarlo a mano o combinarlo con Alpine.js / Preline.
