Antes se llamaba Tailwind UI; se renombró a Tailwind Plus cuando sumó plantillas completas y bloques de aplicación además de los componentes sueltos. Es de pago (con vista previa gratuita del código de cada componente), a diferencia de HyperUI o Flowbite.

## Cómo lo uso

Cada componente muestra el markup completo (HTML plano con clases de Tailwind, sin JS extra salvo que el componente lo necesite) listo para copiar. No es un paquete npm: no hay instalación ni configuración, solo requiere tener Tailwind CSS configurado en el proyecto.

## Tips

- Los bloques de "Application UI" (tablas, formularios, navegación) están mejor pensados para dashboards que los de "Marketing" (hero, pricing, footers).
- Muchos componentes también tienen versión en React y Vue — útil como referencia de accesibilidad (aria, foco) aunque el proyecto termine usando otra librería.
