## Qué esperar

El contenido es de nivel introductorio y está orientado al mundo laboral más que a la implementación técnica: qué es la IA generativa, cómo cambia un puesto de trabajo, cómo usarla en tareas del día a día.

## Cómo encaja para alguien que ya programa

Es útil por dos motivos concretos, y conviene tenerlos claros para no esperar otra cosa:

- **La señal en el perfil.** El certificado aparece en LinkedIn, que es donde miran los reclutadores.
- **El vocabulario compartido.** Ayuda a hablar de IA con perfiles de negocio, producto o recursos humanos.

Para la parte de construcción real, agentes, MCP y evaluación, es mejor el [bootcamp de Python + Agentes](/courses/cursos-microsoft/microsoft-reactor-python-agentes) o los currículos de GitHub del [Centro de estudiantes](/courses/cursos-microsoft/microsoft-learn-student-hub).
