Plugin partner del marketplace de Cursor que integra Linear — permite leer y crear issues, ver el estado de proyectos, sin salir del editor.

## Instalar

```text
Cursor Settings → Marketplace → buscar "Linear" → Install
```

## Qué hace

Expone las herramientas de Linear (crear issue, buscar, actualizar estado) directamente al agente — útil para el flujo "encuentra el bug que reporté, arréglalo y cierra el issue" en una sola sesión.

## Consideraciones

- Equivalente a configurar el [MCP de Linear](/skills/ia-mcp/mcp-linear) a mano — la diferencia es que el plugin de Cursor viene con la config y el auth flow ya resueltos desde el marketplace.
