Plugin partner del marketplace de Cursor que conecta con Figma — el agente puede leer un diseño (capas, estilos, medidas) directamente para generar el código que lo implementa, en vez de que alguien describa el diseño a mano.

## Instalar

```text
Cursor Settings → Marketplace → buscar "Figma" → Install
```

## Cuándo usarlo

- Pasar de un diseño en Figma a componentes reales sin transcribir medidas/colores a mano.
- Combinado con [frontend-design](/skills/ia-skills/skill-frontend-design) para casos donde no hay un diseño de Figma previo y hay que proponer la dirección estética primero.

## Consideraciones

- Requiere acceso al archivo de Figma (permisos del workspace) — no funciona sobre un link público sin los permisos correspondientes.
