**Dribbble** es una galería donde diseñadores y estudios publican pequeñas presentaciones de su trabajo, llamadas _shots_. Sirve para explorar páginas web, aplicaciones, dashboards, sistemas de marca, ilustraciones y mockups por tema, estilo o color.

## Cómo buscar referencias útiles

Las búsquedas en inglés suelen producir más resultados. En lugar de buscar solo `website`, combina el tipo de producto con la pantalla o el problema:

```text
fintech onboarding mobile
saas analytics dashboard
developer portfolio dark
ecommerce checkout web
website mockup
```

Conviene reunir entre cinco y diez referencias y anotar qué se rescata de cada una: jerarquía, tipografía, ritmo, color, navegación o presentación del contenido. El resultado debe ser una dirección propia, no una mezcla literal de pantallas ajenas.

## Qué se puede estudiar

| Aspecto       | En qué fijarse                                                   |
| ------------- | ---------------------------------------------------------------- |
| Jerarquía     | Qué llama la atención primero y cómo conduce a la acción         |
| Composición   | Ancho, columnas, espacios, alineaciones y densidad                |
| Tipografía    | Contraste entre títulos, texto, etiquetas y cifras               |
| Color         | Relación entre superficies, texto, acciones y estados            |
| Presentación  | Cómo se muestra una web dentro de dispositivos o escenas         |

## Límites de los mockups

Un _shot_ suele mostrar el estado ideal de una interfaz, no el producto completo. Puede omitir navegación real, errores, carga, contenido largo, accesibilidad y comportamiento adaptable. Úsalo para formular preguntas visuales y valida las respuestas con contenido y dispositivos reales.

Dribbble tampoco es una biblioteca donde todo sea descargable. Cada trabajo pertenece a su autor y algunos enlazan a productos, plantillas o archivos externos con licencias diferentes. Ver una imagen o guardarla como referencia no concede permiso para copiarla, redistribuirla o usar sus recursos en un producto.
