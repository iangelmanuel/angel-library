**Pinterest** es una plataforma de descubrimiento visual. Cada imagen o video es un _Pin_ que se puede guardar en tableros, organizar por secciones y compartir con colaboradores. Para diseño funciona bien como moodboard porque mezcla referencias de interfaces con fotografía, editorial, arquitectura, moda y marcas.

## Flujo para construir un moodboard

1. Crea un tablero con el nombre y el objetivo del proyecto; puede ser secreto si aún no debe hacerse público.
2. Divide el tablero en secciones como `layout`, `tipografía`, `color`, `fotografía` y `movimiento`.
3. Empieza con búsquedas concretas: `editorial portfolio typography`, `mobile finance onboarding` o `brutalist web design`.
4. Guarda primero con amplitud y después elimina lo que no apoye una dirección coherente.
5. Resume el resultado en decisiones aplicables: paleta, escala tipográfica, densidad, formas y tratamiento de imágenes.

## Búsqueda visual

Pinterest Lens permite subir una imagen o seleccionar una zona de un Pin para encontrar objetos, composiciones y estilos parecidos. Es especialmente útil cuando reconoces una estética pero no sabes cómo describirla con palabras.

La recomendación se adapta a lo que guardas. Para evitar que el tablero termine lleno de variaciones del mismo patrón, busca deliberadamente referencias contrarias y consulta también productos reales, no solo imágenes recomendadas por el algoritmo.

## Antes de reutilizar una imagen

Guardar un Pin organiza una referencia; **no transfiere sus derechos de uso**. Abre el enlace original, identifica al autor y revisa la licencia antes de descargar, publicar o incorporar una imagen a un producto. Si no se puede encontrar la fuente o el permiso, úsala únicamente como inspiración interna.
