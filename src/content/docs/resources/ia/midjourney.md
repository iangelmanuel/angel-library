**Midjourney** es un servicio de generación visual desde texto e imágenes de referencia. Su aplicación web permite crear, comparar variaciones, editar regiones, ampliar el encuadre y organizar resultados; también puede animar una imagen inicial como un video corto.

## Cómo empezar

Midjourney requiere una cuenta y una suscripción activa para generar. El flujo principal está en la sección **Create** de [midjourney.com](https://www.midjourney.com/): se escribe una instrucción, se añaden referencias si hacen falta y se generan varias propuestas que después se pueden variar o editar.

Un prompt útil separa decisiones en vez de acumular adjetivos:

```text
sujeto + entorno + composición + iluminación + material o técnica + atmósfera
```

Para un proyecto de interfaz suele funcionar mejor generar **referencias de dirección artística** —fotografía, textura, iluminación o escenario— y construir después la UI con componentes reales. El texto incrustado, la legibilidad y los estados de interacción siempre deben revisarse fuera de la imagen.

## Para qué encaja

- Moodboards y exploración rápida de varias direcciones visuales.
- Imágenes conceptuales para una portada, campaña o presentación.
- Variaciones de composición, color, iluminación y estilo.
- Primeros fotogramas que después se convierten en clips cortos.

## Privacidad, coste y uso final

Las generaciones consumen tiempo de GPU incluido en el plan. El video cuesta más que una imagen y algunas modalidades dependen del nivel de suscripción, por lo que conviene hacer pruebas pequeñas antes de producir muchas variantes.

Las creaciones pueden ser visibles para otros usuarios. **Stealth Mode** permite hacerlas privadas únicamente en los planes que lo incluyen y no vuelve privado automáticamente el material anterior. No subas referencias confidenciales sin revisar primero la visibilidad activa.

Antes de usar un resultado comercialmente, revisa los términos vigentes del plan, los derechos de las referencias cargadas y posibles marcas, personajes o personas reconocibles. Una imagen generada sigue necesitando revisión humana de anatomía, texto, continuidad y adecuación a la marca.
