## Git y GitHub

Publicada oficialmente por GitHub y **traducida al español**. Cubre configuración inicial, crear repositorios, ramas, sincronización con el remoto, deshacer cambios e inspeccionar el historial.

Es la referencia adecuada para las primeras semanas. Para entender qué hace realmente cada comando, la categoría [Git & GitHub](/categories/git) de esta biblioteca entra en el modelo mental.

## Flexbox y Grid

Recoge en una página las propiedades de los dos sistemas de disposición de CSS, que son justo las que más se olvidan: la diferencia entre `justify-content` y `align-items`, qué va en el contenedor y qué en los hijos, y la sintaxis de `grid-template-areas`.

## Por qué en PDF

Una hoja de referencia impresa se consulta sin cambiar de ventana ni romper la concentración. Como son PDF alojados en servidores ajenos, conviene **descargarlos** en vez de depender del enlace.
