Best practices de React curadas por el equipo de Vercel — guía al agente hacia los patrones recomendados actuales (Server Components, manejo de estado, composición) y lejos de antipatrones comunes.

## Instalar

```bash
npx skills add https://github.com/vercel-labs/agent-skills --skill vercel-react-best-practices
```

## Fuente

[skills.sh — vercel-labs/agent-skills](https://www.skills.sh) — 645K+ instalaciones.

## Cuándo usarlo

- Cualquier proyecto React/Next.js — como skill de fondo que mantiene el código generado alineado con prácticas actuales, no solo con lo que el modelo "recuerda" de su entrenamiento.
- Útil junto a [vercel-composition-patterns](/skills/skill-vercel-composition-patterns) para composición de componentes específicamente.

## Consideraciones

- Complementa, no reemplaza, las guías de esta biblioteca sobre hooks nativos (ver [useState](/guides/react-usestate), [useEffect](/guides/react-useeffect), etc.) — el skill da convenciones generales, las guías explican el mecanismo de cada hook en detalle.
