Fuerza convenciones de equipo consistentes al escribir Express en TypeScript — estándares de nombres, organización de archivos, el patrón RO-RO (Receive an Object, Return an Object) para funciones con muchos parámetros, y reglas estrictas de TypeScript.

## Instalar

```bash
npx skills add https://github.com/mindrally/skills --skill express-typescript
```

## Fuente

[skills.sh](https://www.skills.sh) — mindrally/skills.

## Cuándo usarlo

- Proyectos en equipo donde la consistencia de estilo importa más que en un proyecto solo — evita que cada sesión del agente "invente" una convención distinta.
- Junto a [nodejs-backend-patterns](/skills/skill-nodejs-backend-patterns) para arquitectura general + convenciones de código, ambos cubriendo capas distintas del mismo problema.

## Consideraciones

- Es un skill de conveciones de **estilo**, no de arquitectura — no reemplaza entender el patrón de capas de [Express en esta biblioteca](/patterns/backend-mvc-structure), lo complementa.
