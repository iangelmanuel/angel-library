Un repositorio comunitario con comandos slash profesionales para Claude Code, listos para copiar — cubre workflows que llevaría bastante tiempo armar desde cero: code review estructurado, feature creation, security auditing, análisis de arquitectura, y más. 55+ agentes especializados incluidos.

## Instalar

```bash
git clone https://github.com/qdhenry/Claude-Command-Suite
cp -r Claude-Command-Suite/commands ~/.claude/commands/
```

O revisar el repo y copiar solo los comandos puntuales que hagan falta, en vez de todos.

## Qué incluye (categorías principales)

- **Code review** — revisión estructurada multi-paso
- **Feature creation** — scaffolding directamente feature nueva siguiendo convenciones del repo
- **Security auditing** — auditoría más profunda que un comando suelto
- **Architectural analysis** — evaluación de decisiones de arquitectura

## Consideraciones

- Es un proyecto de terceros, no oficial de Anthropic — revisar el contenido de los comandos antes de instalarlos a ciegas, como con cualquier código que se copia de un repo externo.
- Buen punto de partida para ver "cómo se ve un comando bien armado" incluso si al final solo se usan 2-3 de los 55, no el paquete completo.
