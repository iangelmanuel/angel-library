Ayuda a crear interfaces con una dirección estética intencional en vez del look genérico típico de UI generada por IA — guía la elección de tipografía, paleta de color y layout, y genera código alineado a esa dirección (HTML/CSS/JS, React o Vue), evitando fuentes sobreusadas y layouts predecibles.

## Instalar

```bash
npx skills add https://github.com/anthropics/skills --skill frontend-design
```

## Fuente

[skills.sh/anthropics/skills/frontend-design](https://www.skills.sh/anthropics/skills/frontend-design) — oficial de Anthropic, 784K+ instalaciones.

## Cuándo usarlo

- Landing pages, marketing sites, cualquier UI donde la estética importa tanto como la funcionalidad.
- Como punto de partida de dirección visual antes de picar código — pedirle que proponga 2-3 direcciones distintas antes de elegir una.

## Consideraciones

- No reemplaza un sistema de diseño ya establecido — si el proyecto ya tiene tokens de diseño definidos (como este mismo sitio, con sus variables en `global.css`), decile explícitamente que los respete en vez de proponer una paleta nueva.
